# core › geometry

> Draft under discussion. Statuses: **built** = in `packages/aslnut`, tested on WebGPU and WebGL2; **partly** = some of it there; **planned** = not there yet (a research prototype may exist).

**In one line:** depiction: things as they are, everything that has a form of its own: shapes made by your code (a shape, a builder of few verbs, parts, levels, instances, checks, recipes); models imported from files; the landform (sources composed in one place, the ground terraformed); networks made from lines (analysis, lanes, walkways, cross-sections, junctions, the structures made from them, and the ground clamped below); and zones (kinds, cutting, and the rules that place things: scattering, frontage).

Concepts: [shapes](../../concepts/shapes.md) · [formats](../../concepts/formats.md) · [networks](../../concepts/networks.md) · [the fabric](../../concepts/fabric.md) · [real-world authoring](../../concepts/real-world-authoring.md) · [presence](../../concepts/presence.md) · marks (data as signs) are in [core › encoding](encoding.md)

## Example

```ts
const crate = shape({
  id: 'crate',
  params: { size: num(.3, 2, .6), color: color('#9a6b3c') },
  build: (b, p) => b.solid('box', { size: p.size, at: [0, p.size / 2, 0], color: p.color }),
});
w.add(
  entities({ id: 'crates', shape: crate, data: rows, params: d => ({ size: d.size }) }),
);
```
