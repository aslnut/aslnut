# core › encoding

> Draft under discussion. Statuses: **built** = in `packages/aslnut`, tested on WebGPU and WebGL2; **partly** = some of it there; **planned** = not there yet (a research prototype may exist).

**In one line:** data as signs: the marks (symbols, lines, areas, draped on the ground, or your own); the scales that turn a value into a look, read from the whole data so the same value always gives the same look; the layers (one dataset said one way: its signs, labels inside, its legend, its place in the stack); and the join (new, changed and gone features, by id: only those redraw).

Depiction (things as they are) is [core › geometry](geometry.md); render draws both. A layer never reads the camera: its data loads once, its look comes from the feature and the settings only.

Concepts: [encoding and layers](../../concepts/encoding.md) · [observation](../../concepts/observation.md) · [presence](../../concepts/presence.md) · [order](../../concepts/order.md) · [reveal](../../concepts/reveal.md) · [configurable](../../concepts/configurable.md)

## API: marks

Every mark takes the shared props (`id`, `data`, `when`, `order`, `opacity`, `reveal`, `hover`, `on`; see [world](world.md#elements-props)); a mark alone is a layer of one sign. `Fn<T>` = a constant, `d =>`, `s =>` or `(d, s) =>` (`s` gives a look the time and the state, never the view: the same value, the same look at every zoom). A feature's reveal plays once: one that leaves the data and comes back (a source following the view hands back what a zoom took away) keeps its first birth, never revealed from nothing again; the last 5000 that left are remembered.

## API: scales, layers, join

| item | signature | params (type = default) | returns | status | example |
|---|---|---|---|---|---|
| `scales` | `scale.linear \| log \| sqrt \| quantile \| quantize \| threshold \| jenks \| pretty \| category (value, opts)` | `value: d => number` · `domain?: [a, b] \| breaks \| categories \| 'auto' = 'auto'` ('auto': read once from the whole source when it is complete, and again only when the data changes (simulation, time, rows joined anew), never when the view moves; over a tiled source 'auto' is an error with its fix: give the domain) · `range?: Ramp \| [from, to] \| looks[]` · `n?: int = 5` · `clamp?: boolean = true` · `missing?` · `reverse?` · category: `map?`, `other?` | `d => look` (usable as any prop; the same value, the same look, always) · `scale.legend()` · `scale.breaks` | [built] | `color: scale.quantile(d => d.props.rate, { range: 'reds', n: 5 })` |
| `layers/layer` | `layer(options)` · a mark alone is a layer of one sign (`area`, `line`, `points` …) | `id: string` · `label?: string` · `data: Source \| Feature[]` (loaded once, shared by its signs) · its signs, each a mark's options without `data`: `area?` (fill and outline), `line?`, `points?`, `extrusion?`, `labels?` (below) · `when?` (none by default: no gate) · `opacity?` · `tooltip?`, `hover?`, `onTap?`, `onHover?`, `select?`, `drape?` (shared by its signs) | `Layer` (an element: one id, one switch, one opacity, one place in the stack, one pick: a sign's feature reported as the layer's; `layer.signs`, `layer.labels`, `layer.joined`) | [built] (`layer.setProps({ line: { … } })`: a sign it has changes, one it did not have is added: made from the layer's data and shared options, put in its place (fill, extrusion, line, points), attached at once in a world (settled waits for it); a fill added first moves the layer to the fills' band; labels added later join the world with it and leave with it) | `layer({ id: 'suburbs', data, area: { color: scale.quantile(km2) }, labels: { text: d => d.props.name } })` |
| `layers/labels` | a layer's `labels: { … }` (a layer of names alone: `layer({ data, labels })`) | the text mark's options (`text`, `priority`, `size`, `color`, `halo`, `font`, `anchor`, `offset`, `at`, `collide`, `feature`, `filter`) with readable defaults (`halo: 2`, `collide: true`, `size: 12`) | labels decided once: an anchor per feature computed once (a point's place, a line's middle, a place well inside an area's largest part), the text and priority read when the data comes, one fixed order (priority, then the feature's id), collision with hysteresis in time (decided from scratch in that order each frame, the same on every device; a change shows at once, then holds 0.25 s before it may change again: nothing is left to change once the orbit stops) shared by every layer's labels (the top of the stack first), a label that stayed never fades in again; drawn in the labels' band over every fill, owned by its layer (shown, faded, stacked with it) | [built] | `labels: { text: d => d.props.name, priority: d => d.props.pop }` |

## Example

```ts
// a statement: one dataset, its fill and its names, its legend, its place in the stack
w.add(layer({
  id: 'suburbs', label: 'Suburbs by area',
  data: data.wfs(WFS, { typeName: 'ns:suburbs', extent: [144.9, -38.0, 145.3, -37.8] }),
  area: { color: scale.quantile((d) => d.props.km2, { n: 5, range: 'ylgnbu' }), opacity: 0.35, outline: { color: '#fff', width: 1 } },
  labels: { text: (d) => d.props.name, priority: (d) => d.props.km2, size: 13, halo: { width: 3, color: '#fffe' } },
}));
// one mark, one sign
w.add(line({ id: 'creeks', data: creeks, width: 2.2, color: '#2563eb' }));
w.reorder(['suburbs', 'creeks']);          // the stack, bottom first
```
